# L0. Описательная аналитика

Что произошло.

Сейчас у тебя уже есть.

```text
Частоты
Сигнатуры
Парные связи
Профиль поведения
Топ эмоций
Топ триггеров
```

Примеры:

```text
42% approach
35% avoid
23% compensate
```

---

# L1. Поведенческие контуры

Откуда и куда течёт поведение.

Объединяет:

* CBT
* Functional Analysis
* часть DBT

Сущности:

```text
trigger
emotion
behavior
stc
ltc
```

Артефакты:

```text
Топ лупов
Топ цепочек
Топ копингов
Поведенческие вилки
```

Пример:

```text
criticism
→ shame
→ avoid
→ relief
```

---

# L2. Временная динамика

Что меняется со временем.

Объединяет:

* Process Mining
* часть Dynamical Systems

Сущности:

```text
sequence
trend
trajectory
```

Артефакты:

```text
Новые паттерны
Умирающие паттерны
Рост/спад эмоций
Смена стратегий
```

---

# L3. Пространство состояний

Самый интересный слой.

Объединяет:

* Dynamical Systems
* State Space
* Attractors

Сущности:

```text
state
trajectory
attractor
transition
```

Артефакты:

```text
Аттракторы
Бассейны притяжения
Переходы
Застревания
Пустоты
```

Типа:

```text
человек постоянно
возвращается в состояние:

стыд
+
оценка
+
avoid
```

---

Сущности:


Артефакты:

# L5. Narrative Layer

Объединяет:

* Narrative

Сущности:

```text

part
```

Артефакты:

```text
повторяющиеся сюжеты
внутренние персонажи
идентичность
```

Пример:

```text
Исследователь

```

# L6. Prediction Layer

Объединяет:

* Predictive Processing
* Active Inference
* Counterfactual Modeling

Сущности:

```text
prediction
expectation
error
alternative outcome
```

Артефакты:

```text
что человек прогнозирует
где ошибается

```

# L7. Regulatory Layer

Объединяет:

* Cybernetics
* Control Theory

Сущности:

```text
goal

```

Артефакты:

```text

```

---

# L8. Insight Mining

Верхушка пирамиды.

Питается всеми слоями.

Артефакты:

```text
слепые зоны
контрпаттерны
аномалии
точки роста
инсайты
```

Пример:

```text
Обычно критика ведёт к avoid.

Но в трёх случаях
критика привела к продуктивному approach.

Что было иначе?
```

---

# Психогеография

Я бы не выделял отдельно.

Это визуализация для:

```text
L3 State Space
+
L4 Graph
+
L8 Insight Layer
```

То есть не аналитика.

А способ отображения.

---

В итоге получается компактное дерево:

```text
L0 Описательная аналитика

L1 Поведенческие контуры

L2 Временная динамика

L3 Пространство состояний

L4 Граф личности

L5 Narrative / Parts

L6 Prediction Layer

L7 Regulatory Layer

L8 Insight Mining
```

Это выглядит как естественная эволюция твоего текущего CBT-графа без привязки к конкретным психотерапевтическим школам.
