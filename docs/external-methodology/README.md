# MISHA External Methodology

This folder contains external-facing concept and communication materials for
MISHA. It is written for investors, doctors, psychologists, partners, technical
stakeholders, marketing/SMM teams, and early users.

The documents explain what MISHA is, what it is not, why it matters, and how to
talk about it safely during the beta stage.

MISHA is a self-observation tool. It helps users describe concrete life
episodes, decompose them into structured parts, and notice repeated emotional,
cognitive, bodily, and behavioral patterns over time.

MISHA is not a therapist, AI psychologist, treatment tool, diagnostic tool,
crisis support tool, or replacement for professional help.

This folder is not backend architecture, product implementation, or internal
system documentation. It describes how MISHA should be understood and explained
externally.

## Language Versions

English and Russian files are paired versions of the same external
methodology. They should stay aligned in meaning, safety boundaries, and beta
positioning. Russian files should use natural Russian, not literal translation
when a direct translation sounds awkward.

## Included Files

- `01-concept-guide.md`: main stakeholder guide for MISHA's concept, user
  journey, beta-stage positioning, boundaries, and core terms.
- `02-one-pager.md`: compact overview that can be sent to most stakeholders.
- `03-stakeholder-pitches.md`: audience-specific explanations for investors,
  doctors and psychologists, technical stakeholders, and users.
- `04-language-and-safety.md`: canonical language and safety guide. Use this
  file as the source of truth for allowed claims, prohibited claims, crisis
  boundaries, and safe rewrites.
- `05-message-house.md`: marketing and SMM narrative, including short content
  hooks.
