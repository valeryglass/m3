# MISHA External Methodology

This folder contains external-facing concept and communication docs for MISHA.
It is written for investors, doctors, psychologists, partners, technical
stakeholders, marketing/SMM, and early users.

These docs explain what MISHA is, what it is not, why it matters, and how to
talk about it clearly. They are intended for pitching, stakeholder alignment,
website copy, social content, and early user explanation.

This folder is not backend architecture, product implementation, or internal
system documentation. It does not describe how MISHA is built. It describes how
MISHA should be understood and communicated.

## Included files

- `01-concept-guide.md`: Main stakeholder guide for MISHA's concept,
  boundaries, user value, and language.
- `02-one-pager.md`: Compact universal overview that can be sent to almost any
  stakeholder.
- `03-stakeholder-pitches.md`: Audience-specific explanations for investors,
  doctors and psychologists, technical stakeholders, and users.
- `04-language-and-safety.md`: Allowed language, prohibited language, safe
  rewrites, and communication principles.
- `05-message-house.md`: Marketing and SMM narrative, including short content
  hooks.
