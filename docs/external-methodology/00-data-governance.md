# Управление данными: первый черновик

Статус: первый черновик, TBD.

## Назначение

Описать внешним языком, как MISHA работает со слоями данных, обработкой,
хранением, экспортами и правилами управления данными.

Этот документ является методологическим черновиком.

## Слои данных

- Наблюдаемые исходные данные: сообщения пользователя, ответы по эпизоду,
  Telegram-идентификаторы и исходная metadata, необходимые для работы alpha.
- Структурированные эпизоды: наблюдаемые CBT-факты эпизода, сохраненные как
  исходные артефакты.
- Annotation-runs: устойчивые производные graph-аннотации, созданные на основе
  наблюдаемых эпизодов.
- Вычисляемые представления: graph-сводки по запросу и пользовательский текст
  отчета.
- Явные экспорты: map payload JSON и map HTML, когда они намеренно
  сгенерированы.
- UX-metadata: события взаимодействия без сырого текста ответов.
- Admin records: userlist и metadata одобрения для приватного alpha-доступа.

## Основной поток данных

```text
Telegram-взаимодействие
  -> наблюдаемый эпизод
  -> выбранный annotation-run
  -> вычисляемый GraphReport
  -> profile summary / details / map payload
```

Reports и payloads являются проекциями. Они не являются записями-источниками
истины и при необходимости должны пересоздаваться из наблюдаемых эпизодов и
выбранного annotation-run.

## LLM и tool processing

Выбранные данные могут обрабатываться AI/tools для аннотации, reporting,
quality review, работы с code/docs или поддержки анализа. Производные outputs
должны сохранять границу между наблюдаемыми свидетельствами и интерпретацией.

Система должна избегать языка, который представляет сгенерированные паттерны
как медицинские, диагностические или объективные утверждения.

## Хранение и доступ

Private alpha data хранится локально в project data directories. Owner/admin
review может происходить для эксплуатации, отладки, аннотации, safety review и
quality improvement.

Пользователи могут запросить export или deletion через Telegram contact path.
Backups и logs могут требовать разумного времени на очистку.

## Политика экспорта

Сгенерированные report-файлы являются optional debug/export snapshots. Они не
являются active storage. Map payload JSON и map HTML являются явными
техническими экспортами для visual/map experiments.

## Риски и безопасность

- Пользователи могут делиться чувствительной личной, эмоциональной,
  поведенческой или связанной со здоровьем информацией.
- Analytics может быть неполной, неточной, вводящей в заблуждение или
  сгенерированной с ошибкой.
- MISHA не является терапией, диагнозом, медицинским советом или экстренной
  поддержкой.
- Пользователям не следует делиться информацией, которую им некомфортно хранить
  или обрабатывать в экспериментальном alpha-сервисе.
